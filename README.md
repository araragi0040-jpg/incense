# 香り日和 Mock v002 修正版2

## 今回の修正
- 下部タブを常時画面下に固定
- 親要素の `backdrop-filter` が `position: fixed` の基準を変えてしまう環境差を回避
- iPhone等のセーフエリアを考慮
- 下部タブに隠れないよう本文下余白を自動確保
- タブ切替時にページ上部へ戻るよう改善
- 下部導線（5ステップ）を横スクロール対応にし、スマホで崩れにくく改善
- タブのタップ領域と選択状態を見やすく改善
- キーボード操作時のフォーカス表示を追加

## 起動
`index.html` をブラウザで開いてください。

データ保存は LocalStorage を使用しますが、保存できない環境でもセッション中の操作は継続できます。
