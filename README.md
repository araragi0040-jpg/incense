# 香り日和 Mock v002 修正版

v002で「画面を押しても反応しない」問題を修正した版です。

## 修正点
- `localStorage` が利用できないプレビュー環境でも、クリック時に処理が止まらないよう修正
- `saveState()` を安全化し、保存不可の場合はそのセッション中のメモリ上で動作
- `index.html` に CSS / JavaScript を内包し、単体ファイルで操作できるよう変更
- お香選択時におすすめ計算で毎回選択が上書きされる挙動を修正
- 既存の v002 UI・レポート・数量調整・購入確認導線は維持

## 起動
`index.html` をブラウザで開いてください。
外部ファイルを読み込まないため、ChatGPTのファイルプレビューやローカル環境でも動作しやすくしています。
