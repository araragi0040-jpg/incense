# 香り日和 Mock v002

v001をベースに、ポスターのUIイメージへ寄せた v002 です。

## 主な変更点
- 全体トーンをポスター寄りの淡いベージュ × グリーンに調整
- 画面構成を「今日の記録」「振り返りレポート」「次回購入のおすすめ」に寄せて再設計
- 記録画面を「状態入力＋使用したお香選択」の1画面構成に変更
- レポート画面にラインチャート、ドーナツ風表示、相性表示を追加
- 購入画面を「おすすめブラッシュアップ＆数量調整」中心のUIに変更
- 商品は「お香くん / お香ちゃん」の2種類で統一

## 使い方
1. index.html をブラウザで開く
2. 画面下ナビから「ホーム / 記録 / レポート / 購入」を切替
3. 記録画面で状態と使用商品を選び、「記録する」で履歴・レポート・購入提案へ反映
4. 購入画面で数量を ± で調整し、購入導線のモックを確認

## 備考
- データは LocalStorage 保存です
- 決済・EC連携は未実装で、購入確認モーダルまでです
