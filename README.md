# お香 × コンディション記録アプリ Mock v001

提案用のスマホWebモックです。バックエンド・ログイン・決済・EC連携は未実装で、画面遷移と主要導線の確認を目的としています。

## v001で確認できること

- ホーム：今日の記録への導線、今日の一問、連続記録、今日のお香おすすめ
- 商品：お香くん / お香ちゃん の2種類
- 今日の記録：気分、心の元気、身体の疲れ、集中度を1〜5で入力
- おすすめ提案：入力値に応じて「お香くん / お香ちゃん」を簡易ルールで切替
- 使用履歴：今日使うボタンで履歴を追加、推定残量を減算
- レポート：7日間の気分、よく使う香り、使用履歴
- 次回購入：おすすめ数量を提示し、お客様側で±変更可能
- 購入確認：クリックで購入内容確認モーダルへ（実決済なし）
- LocalStorage：操作内容をブラウザに保存

## 利用フロー

質問・記録 → おすすめ提案 → 使用履歴 → おすすめブラッシュアップ＆数量調整 → 購入

## 開き方

`index.html` をブラウザで直接開いてください。

より確実に動かす場合はフォルダ内で簡易サーバーを起動します。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。
