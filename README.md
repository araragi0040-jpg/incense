# 香り日和 Mock v003

v002 修正版2をベースに、初回診断（香りタイプ診断）を追加したモックです。

## v003 追加内容
- 初回起動時に診断導線を表示
- 5つの質問を1問ずつ回答
- 回答から「お香くん / お香ちゃん」の初回おすすめを算出
- 使用頻度の回答から初回購入数量の目安を作成
- 診断結果を次回購入提案の初期値へ反映
- ホームから診断をやり直せる
- 「モックを先に見る」で診断をスキップ可能

## 既存機能
- 今日の記録
- 今日の一問
- お香の使用記録
- 振り返りレポート
- 使用履歴
- おすすめブラッシュアップ・数量調整
- 購入確認モーダル

データ保存は LocalStorage を利用し、利用できない環境ではセッション内メモリで動作します。
